## Diagnose a provider failure

[Open the error classifier](/demos/errors/). Pick a provider example or paste a failure. The real
Core classifier names the kind and shows what can fix it. Nothing you type leaves your browser.

For a smaller first step, [try the transient-error example](/#example). Choose a failure and see
whether waiting could help.

## Run an agent locally

[The Agents quickstart](/agents/getting-started/) runs the published offline example on your own
machine. It uses a scripted provider, with no API key or paid call.

The React chat demo will use the published package rather than a separate imitation.
[Follow that work](/react/) or [find an example you can run now](/examples/).
