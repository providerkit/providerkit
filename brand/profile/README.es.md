# <img src="https://raw.githubusercontent.com/providerkit/providerkit/main/brand/providerkit-mark-128.png" alt="" width="36" height="36" align="absmiddle"> providerkit

[English](https://github.com/providerkit) · [Português](https://github.com/providerkit/.github/blob/main/profile/README.pt-BR.md) · Español

Usa TypeScript para llamar a modelos de IA, ejecutar agentes y crear interfaces de chat. Empieza por el paquete que necesites:

- [Core](https://providerkit.dev/core/) llama a modelos de distintos proveedores, muestra la respuesta a medida que llega e indica cuándo conviene volver a intentarlo.
- [Agents](https://providerkit.dev/agents/) ejecuta herramientas y flujos de trabajo. Puede esperar a que alguien responda o dé su aprobación antes de continuar.
- [React](https://providerkit.dev/react/) incluye hooks de chat y componentes opcionales para mostrar mensajes y lo que hacen las herramientas. Tú eliges los estilos.

[Prueba una demo](https://providerkit.dev/demos/) sin clave de API, [consulta los primeros pasos](https://providerkit.dev/start/) o [lee el código](https://github.com/providerkit/providerkit).
