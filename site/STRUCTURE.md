# Site navigation

A developer can come here with a package in mind or with a task to solve. The header keeps the
three package names together. Examples, demos and the API reference are a second group, still
one click away. The home link is the mark and name together.

```text
Desktop: providerkit   Core · Agents · React   Examples · Demos · API reference   Search · GitHub · Theme
Phone:   providerkit   Search · Menu
```

The desktop row stays one line. Search keeps its keyboard shortcut even when only the magnifier
fits. A line under the section name shows where you are; it does not rely on color alone.

On a phone, a guide opens Starlight's docs drawer, with the current section expanded. The home
page has no guide tree, so its menu offers the six destinations directly. Both menus include
GitHub and the theme selector. Escape closes the menu and returns to the button. There is no
account menu on this public site.

Keep guide chapters in the sidebar and actions such as copying Markdown beside the page title.
The header does not repeat either list. None of the pages or URLs changes with the viewport.
The home page still leads with the task example, and reference pages still lead with the API.
