## Diagnose a provider failure

[Open the error classifier](/demos/errors/). Pick a provider example or paste a failure. The real
Core classifier names the kind and shows what can fix it. Nothing you type leaves your browser.
For a smaller first step, [ask whether waiting helps](/?task=errors#example).

## Run a task

[Run the agent example](/demos/agent/). A scripted provider asks a real SDK tool for two sample
tasks. Watch its activity and stop the local execution. No model key or paid request is used.
[The quickstart](/agents/getting-started/) also runs offline on your own machine.

## Build a chat

[Try the React components](/demos/chat/). Send a sample message, stop output or choose a refused
send to see the draft stay intact. The demo uses the published hooks and components with this
site's styles. Text stays in the current tab; no server or provider receives it.

These examples show real library behavior with local data. Your application supplies the trusted
server, permissions and persistent execution. [Find a complete source example](/examples/).
